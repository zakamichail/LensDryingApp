Индекс экстраполяции

Здесь это среднее расстояние текущего режима от центра архивной выборки в стандартизованных признаках регрессионных моделей.

Для каждой модели считается z(x) = (x - среднее архива) / стандартное отклонение архива, затем d = sqrt(mean(z²)). Индекс на экране — среднее d по построенным моделям этапа.

Около 0 означает близко к среднему архивному режиму, около 1 — в пределах типичного разброса архива, значения выше 2 означают заметную экстраполяцию.

Оценка риска этапа

Это расчетная вероятность дефектного исхода p для конкретного этапа. Для графика p деф от Tсуш метка дефекта равна 1 для температурного дефекта этапа и 0 для годного этапа.

Значение p деф получается сигмоидной функцией p деф = 1 / (1 + exp(-(k·Tсуш + b))).

Верхняя граница допуска p_high подбирается по архивным прогнозам. Значения выше нее требуют контроля; значения выше расчетной границы p_border считаются режимом на границе допуска.
