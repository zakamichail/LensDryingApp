Индекс экстраполяции

Это среднее расстояние текущего режима от центра архивной выборки в стандартизованных признаках регрессионных моделей этапа.

Для каждой модели считается z(x) = (x - среднее архива) / стандартное отклонение архива, затем d = sqrt(mean(z²)). Показанное значение — среднее d по моделям.

Чем выше индекс, тем дальше расчетный режим от области, хорошо представленной в архиве.

Оценка риска этапа

Это расчетная вероятность дефектного исхода p для этапа. Для графика p деф от Tсуш метка дефекта равна 1 для температурного дефекта этапа и 0 для годного этапа.

Модель строится как сигмоидная функция p деф = 1 / (1 + exp(-(k·Tсуш + b))).

Верхняя граница допуска p_high подбирается по архивным прогнозам. Значения выше нее требуют контроля; значения выше расчетной границы p_border считаются режимом на границе допуска.
